# TimePoll — Сайт для опросов о времени проведения мероприятий

Веб-приложение с календарём для согласования дат и времени мероприятий (с шагом в 30 минут), системой аккаунтов, темами оформления и синхронизацией через **Firebase** (готово к публикации на **GitHub Pages**).

## ✨ Основные возможности
1. **Аккаунты и права администратора:**
   - Администратор может **добавлять, редактировать и удалять** любых пользователей во вкладке **«Пользователи»**.
   - Каждый пользователь может **сменить свой пароль** во вкладке **«Настройки»**: требуется ввести текущий пароль, **дважды ввести новый пароль** и **подтвердить действие** в диалоговом окне.
2. **Мероприятия и предполагаемый промежуток:**
   - Администратор создаёт мероприятие, указывает **предполагаемый промежуток дат и времени** и выбирает **участников**.
   - В календаре и внутри дня предполагаемый промежуток визуально отображается **более светлым**, а даты и часы вне промежутка отмечаются **серым цветом со штриховкой** (при этом пользователи могут отмечать время и вне промежутка).
3. **Календарь и покраска времени (ПКМ):**
   - На верхней панели сайта доступны **3 цвета**:
     - 🟢 **Зелёный** — предпочитаемое время
     - 🔵 **Синий** — свободен в это время
     - 🔴 **Красный** — занят в это время
     - *(а также Ластик для быстрой очистки)*
   - **Правая кнопка мыши (ПКМ)** по дню в календаре — закрашивает сразу весь день (можно также зажать ПКМ и провести по нескольким дням).
   - **Левая кнопка мыши (ЛКМ)** по дню в календаре — открывает детальное расписание этого дня с **шагом в 30 минут** (`00:00 – 00:30`, `00:30 – 01:00`, ..., `23:30 – 24:00`), где слоты также закрашиваются нажатием или протягиванием **ПКМ**.
4. **Вкладка «Настройки» и Темы:**
   - 6 встроенных тем оформления: *Тёмная (Графит)*, *Светлая (Дневная)*, *Полночь (Неон)*, *Изумрудный лес*, *Океанский бриз*, *Тёплый закат*.
   - Настройка подключения к БД **Firebase** (доступна только администратору).

## 🚀 Выгрузка на GitHub Pages и настройка Firebase

1. Загрузите файлы этого репозитория в ваш репозиторий на GitHub и включите **GitHub Pages** (`Settings` -> `Pages` -> `Deploy from a branch: main / root`).
2. Создайте проект в [Firebase Console](https://console.firebase.google.com/), добавьте веб-приложение (`</>`) и скопируйте объект `firebaseConfig`.
3. Включите **Cloud Firestore** (или **Realtime Database**) в режиме тестирования (или разрешите чтение/запись для коллекции `timepoll_data`).
4. Войдите на сайт под администратором (`ivaniva`), перейдите во вкладку **«Настройки»** -> блок **«Настройка БД Firebase»**, вставьте `firebaseConfig` и нажмите **«Сохранить и подключить БД»**.
5. Чтобы другие участники на GitHub Pages автоматически подключались к вашей БД:
   - Нажмите **«🔗 Скопировать ссылку с БД»** и отправьте её участникам (настройки сохранятся у них автоматически при переходе по ссылке), **ИЛИ**
   - Нажмите **«📥 Скачать firebase-config.js»** и замените им файл `js/firebase-config.js` в вашем репозитории на GitHub.
